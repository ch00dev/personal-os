# Personal OS

An AI-powered personal operating system designed to centralize life management, knowledge, projects, goals and productivity.

## Vision

Personal OS aims to become a unified environment for capturing information, organizing responsibilities, managing projects and making better decisions with the support of AI.

## Main Modules

- Dashboard
    
- Areas of Life
    
- Tasks
    
- Projects
    
- Goals
    
- Knowledge Base
    
- Personal Finance
    
- AI Assistant
    
- Integrations
    

## Technology Stack

| Layer          | Technology                 |
| -------------- | -------------------------- |
| Frontend       | Next.js, React, TypeScript |
| UI             | Material UI                |
| Data Fetching  | TanStack Query             |
| Forms          | React Hook Form, Zod       |
| Backend        | Python, FastAPI            |
| Validation     | Pydantic                   |
| ORM            | SQLAlchemy                 |
| Migrations     | Alembic                    |
| Database       | PostgreSQL                 |
| AI             | Pydantic AI, Ollama        |
| Infrastructure | Docker, WSL2               |
| Automation     | n8n                        |
| Communication  | Telegram Bot API           |

Technology choices may evolve as the project develops.
